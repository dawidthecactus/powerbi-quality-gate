# Reproducible PBIQ terminal recordings

This directory contains [VHS](https://github.com/charmbracelet/vhs) tapes that
run the **actual compiled PBIQ CLI** on repository-owned synthetic PBIP fixtures.
They are not images or fake terminal transcripts.

Use the manual `Docs screenshots` GitHub Actions workflow to render four PNGs
without setting up recording software locally. Instructions:
[terminal screenshots](../../docs/terminal-screenshots-02.5.3.3.md).

Generated PNGs are imported into `assets/screenshots/` only after human review.
Temporary `.capture-*.gif` files are intermediate render output, **not** the
short marketing GIF planned for 02.5.3.4.
