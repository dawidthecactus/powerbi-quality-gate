# SM-002.6a: Advisory dependency target grouping

## Motivation

SM-002.5a/5b identifies *candidate references* in DAX measures. It does **not**
prove that a referenced member is invalid. The first private pilot of 883
measures ended with 11 candidate references affecting 7 measures in P01 and
zero remaining in P02. A single missing object can be mentioned by multiple
measures or members, so reviewing only individual rows may duplicate effort.

This milestone is intentionally narrower than a semantic dependency graph. It
adds a **local, opt-in, privacy-safe grouping and review aid** over an existing
private dependency candidate CSV. Each group is a *target hypothesis*, not a
confirmed error, a cause, or a DAX engine verdict.

## Grouping keys

| Candidate kind | Grouped by | Reason |
| --- | --- | --- |
| `unknown_table` | Unknown table qualifier | Missing one table can affect several different members |
| `unknown_qualified_member` | Table qualifier + member | Missing a particular member is distinct from another member of the same table |
| `unresolved_unqualified` | Unqualified `[Name]` | Several measures can reference the same unresolved name, but the actual binding remains context-sensitive |

All identifiers are compared case-insensitively. A group is `shared` only when
its candidates affect **at least two distinct source measures**. Repeated
references from a single measure do not turn a group into a shared one. Groups
are numbered deterministically (`G001`, `G002`, ...), but these IDs may change
if candidate sets or ranking change and must not be used as stable identifiers.

The group count is not equivalent to the number of missing root objects. For
example, two different unknown members in an existing table remain separate
hypotheses, whereas references to different members of the same unknown table
are grouped together. No transitive dependency propagation is inferred.

## Local command

The input must be an **unmodified canonical PBIQ private CSV** generated by
`inspect --measures --dependencies --dependency-review` or by the
SM-002.5c.2 Excel normalizer. Do not pass a semicolon-separated editable CSV
straight from Excel.

```powershell
Set-Location "$HOME\Desktop\Porfolio\powerbi-quality-gate"
$private = Join-Path $HOME 'PBIQ Pilot Private'

python .\scripts\sm002-dependency-root-causes.py `
  --review (Join-Path $private 'sm0025c2-P01-normalized.csv') `
  --case-id P01 `
  --summary-out (Join-Path $private 'sm0026a-P01-summary.json') `
  --private-out (Join-Path $private 'sm0026a-P01-groups.csv') `
  --dry-run
```

If the dry run succeeds, repeat **without** `--dry-run`. Both outputs must have
new filenames; existing files are not overwritten. Output locations and the
source must all be outside any Git worktree. Run P02 against
`sm0025b-P02-dependencies.csv` with `--case-id P02`; an empty candidate list is
supported.

Use `--summary-out` **without** `--private-out` if only anonymous counts are
needed. The terminal prints a small, fixed-label, aggregate-only result and
never prints user-provided object names, model paths or DAX.

## Output / privacy

The JSON summary contains only the anonymous case alias, integer counts,
group-count totals by candidate kind and counts of existing manual review
labels. It contains **no** object identifiers, formulas, file paths, private
notes, or group member names. Even small aggregate counts need manual approval
before publication.

The optional private CSV contains group aliases **and original object names**,
including source measure names and reviewed labels. Keep it locally, outside
Git and sharing tools. The CSV does not contain DAX expressions or external
connections. Spreadsheet-formula-shaped identifiers are escaped.

The source `confirmed_missing` or `confirmed_valid` is **only a user-entered
label**; this command neither opens a PBIP nor executes DAX. Do not publish or
advertise the 11 prior P01 manual labels as engine-proven findings.

## Safety invariants

- Read-only transformation of the input CSV; exclusive output creation, no overwrite.
- Refuse linked/symlink/junction paths, Git worktrees, mixed case IDs,
  malformed rows, duplicates, unknown statuses or candidate kinds.
- No C# parser changes, no SM-002 strict gate changes, and no changes to
  public `audit`, JSON v1/SARIF, binaries or CLI exit-code policy.
- Synthetic-only tests; no real model identifiers in the repository.
- Deduplicated affected-measure counts, not naive reference counts.
