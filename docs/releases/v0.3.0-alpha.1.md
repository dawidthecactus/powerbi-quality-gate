# 🌵 PBIQ v0.3.0-alpha.1

**The first published v0.3 alpha of Power BI Quality Gate.** PBIQ is a local, offline, read-only CLI for Power BI project structure and semantic-model metadata quality.

This is an **early-access prerelease**, not a production certification tool.

## Get started

**[5-minute Quick Start](https://github.com/dawidthecactus/powerbi-quality-gate/blob/main/docs/quick-start.md)**

Download a self-contained executable (no .NET SDK/runtime required):

| Platform | Download |
| --- | --- |
| Windows x64 | [pbiq-win-x64.zip](https://github.com/dawidthecactus/powerbi-quality-gate/releases/download/v0.3.0-alpha.1/pbiq-win-x64.zip) |
| Linux x64 | [pbiq-linux-x64.tar.gz](https://github.com/dawidthecactus/powerbi-quality-gate/releases/download/v0.3.0-alpha.1/pbiq-linux-x64.tar.gz) |
| SHA256 checksums | [SHA256SUMS.txt](https://github.com/dawidthecactus/powerbi-quality-gate/releases/download/v0.3.0-alpha.1/SHA256SUMS.txt) |

First audit on Windows (replace with your local path):

```powershell
.\pbiq\pbiq.exe audit 'C:\Reports\Revenue.SemanticModel' --quiet
```

You can also try the [public synthetic Fabric Git fixture](https://github.com/dawidthecactus/powerbi-quality-gate/tree/v0.3.0-alpha.1/examples/fabric-git) without any private data.

## New since v0.2.0-rc.1

- **Native Fabric Git input**: `audit` directly accepts local `.SemanticModel` folders, without a `.pbip` shortcut.
- **JSON reports**: `audit --format json` with documented schema version `1.0.0`.
- **Verified TMDL source locations**: file/line mappings for supported SM findings, avoiding fabricated coordinates.
- **YAML policies**: optional `.pbiq.yml` for enabling rules, exact object exclusions, and warning/coverage policies.
- **SARIF 2.1.0**: `audit --format sarif` with repository-relative paths for GitHub Code Scanning.
- **Reusable GitHub Action**: outputs `exit-code`, `sarif-path` and `evaluated`; safe upload logic distinguishes completed audits from setup/structure failures.

The `scan` and `inspect` commands remain PBIP-only. The Fabric Git capability applies to `audit`.

## Initial rule pack

| Rule | Check |
| --- | --- |
| `SM-001` | Active bidirectional relationships |
| `SM-002` | Missing format on **confirmed numeric** visible measures |
| `SM-003` | Visible technical/key columns |
| `SM-004` | Inactive relationships |

Warnings are advisory by default. Use `--fail-on-warning` for a strict gate. `PASS WITH COVERAGE GAPS` does not certify that every measure could be classified.

**Exit codes:** `0` = evaluated and permitted by selected policy; `1` = quality gate rejection **or** structural failure; `2` = not evaluated.

## Release validation

- **406/406 xUnit tests** passing.
- Windows and Ubuntu CI and release workflows passed.
- **13 packaged executable smoke scenarios** passed on each platform.
- GitHub Action was tested from an external consumer repository with synthetic models.
- SARIF was successfully uploaded and processed by GitHub Code Scanning. Four rule alerts with source paths were verified.
- Windows self-contained binary passed an independent local checksum/version/JSON/SARIF acceptance test outside the source checkout.

## Known limitations

- Alpha quality rules, not full Microsoft schema validation or a Power BI Desktop compatibility certificate.
- No DAX execution or type inference, data refresh, service authentication or performance analysis.
- No macOS or ARM64 standalone builds.
- Outputs can include object names and source paths. Review confidentiality before sharing.
- Path boundary checks are lexical, not hardened against hostile symlinks/junctions. Use trusted checkouts.
- Some findings cannot be mapped unambiguously to TMDL source lines.
